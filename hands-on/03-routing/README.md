# ハンズオン03: ルーティングの実装

## 学習目標

- パスベースのルーティング
- 動的ルート（パラメータ）の処理
- クエリパラメータの扱い
- ミドルウェアパターンの実装
- 軽量ルーターの自作

## 概要

このハンズオンでは、Cloudflare Workersでのルーティング実装を学びます。
フレームワークを使わず、基本的なルーティング機能を実装することで、
内部の仕組みを理解します。
